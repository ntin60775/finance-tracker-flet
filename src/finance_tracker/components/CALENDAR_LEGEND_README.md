# CalendarLegend Component Documentation

## Обзор

CalendarLegend - это адаптивный компонент легенды для календарного виджета, который отображает все доступные индикаторы календаря в одну строку под календарём с автоматической адаптацией к ширине.

## Основные возможности

### ✅ Реализованные функции

1. **Отображение всех 7 индикаторов**:
   - 🟢 Доходы (зелёная точка)
   - 🔴 Расходы (красная точка)
   - ◆ Плановые транзакции (оранжевый символ)
   - 📋 Отложенные платежи (символ)
   - 💳 Кредитные платежи (символ)
   - 🟡 Кассовые разрывы (жёлтый фон)
   - 🔴 Просроченные платежи (красный фон)

2. **Адаптивность к ширине календаря**:
   - Полный режим: все индикаторы в одну строку при достаточной ширине
   - Компактный режим: приоритетные индикаторы + кнопка "Подробнее"
   - Автоматическое определение доступной ширины

3. **Исправленное модальное окно**:
   - Корректная работа кнопки "Подробнее"
   - Группировка индикаторов по типам (точки, символы, фон)
   - Безопасная обработка page объекта

4. **Улучшенная визуализация**:
   - Консистентность цветов с календарём
   - Правильное выравнивание по центру
   - Подходящие отступы между элементами (20px)
   - Читаемые размеры шрифтов (12px)

5. **Производительность и стабильность**:
   - Обновление без заметных задержек
   - Корректная обработка ошибок при отсутствии page объекта
   - Стабильность при изменении размеров окна
   - Освобождение ресурсов при размонтировании

## Режимы отображения

### Полный режим (DisplayMode.FULL)
- Отображаются все 7 индикаторов в одну строку
- Активируется при достаточной ширине календаря
- Кнопка "Подробнее" не отображается

### Компактный режим (DisplayMode.COMPACT)
- Отображаются приоритетные индикаторы (доходы, расходы первыми)
- Кнопка "Подробнее" для просмотра всех индикаторов
- Активируется при ограниченной ширине

### Модальное окно (DisplayMode.MODAL_ONLY)
- Полная легенда с описаниями в модальном окне
- Группировка по типам: точки, символы, фон
- Открывается по кнопке "Подробнее"

## Обработка ошибок

### Безопасная работа с page объектом

```python
def _safe_get_page(self, event_or_control) -> Optional[ft.Page]:
    """Безопасное получение page объекта."""
    try:
        if hasattr(event_or_control, 'control') and event_or_control.control:
            return event_or_control.control.page
        elif hasattr(event_or_control, 'page'):
            return event_or_control.page
        elif hasattr(self, 'page') and self.page:
            return self.page
        return None
    except AttributeError:
        logger.warning("Не удалось получить page объект для модального окна")
        return None
```

### Fallback значения

- При ошибке вычисления ширины: возврат к 800px
- При ошибке создания UI: fallback легенда с базовыми элементами
- При ошибке модального окна: логирование без прерывания работы
