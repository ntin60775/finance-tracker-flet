# Дорожная карта проекта Finance Tracker Flet

## Обзор проекта

Finance Tracker Flet - десктопное приложение для управления личными финансами, построенное на Python + Flet. Проект активно развивается с использованием спецификаций Kiro для структурированного подхода к разработке.
